# Seascape-Cophylogeny-Marzonie

Data analysis code for the manuscript titled "X"

Lead author Dr Magena Marzonie

Rmarkdowns include all workflow for six species:
Acropora humulis (01_Acropora),
Isopora spp. (02_Isopora),
Montipora spp. (03_Montipora),
Pocillopora damicornis (04_p_damicornis)
Pocillopora verrucosa (05_p_verr)
Pocillopora meandrina (06_p_mea)

Each markdown has the following sections:
Section 1. Data wrangling and QC
Section 2. PCA to define clusters
Section 3. Genetic diversity statistics
Section 4. Gene environment analysis
Section 5. MAGENA ANALYSIS
